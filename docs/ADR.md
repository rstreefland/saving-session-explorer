# Architecture decision record

This table records durable decisions for this small application. **Accepted** is a policy decision,
not a claim that every existing module complies. Record implementation gaps explicitly. Update
rows when implementation catches up; preserve superseded decisions with links to their replacements.
Routine features and refactors do not need a new row.
